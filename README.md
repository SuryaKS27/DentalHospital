# 🦷 SMYL – Dental Hospital Frontend Website

This is the frontend of **SMYL Dental Hospital**, built using **React.js**, **Bootstrap**, and **custom CSS**. It features a clean, responsive UI for patients to explore services, book appointments, and connect with dental professionals.


## 🧰 Tech Stack

- ⚛️ **React.js** – Component-based architecture
- 🎨 **CSS3** – Custom styling
- 🧩 **Bootstrap 5.3** – Responsive layout and UI components

---

## 🌟 Features

- 🏠 Home, About Us, Services, Dentists, Contact pages
- 📅 "Book Now" call-to-action navigation link
- 👤 Rounded Login and Signup buttons
- 📱 Fully responsive design using Bootstrap
- 📎 Clean, semantic UI with logo and brand identity
